# UploaderBot

ربات آپلود فایل تلگرام ساخته‌شده با **Kurigram** (پایتون) و **Tortoise ORM** — دیتابیس کانال تلگرام، پنل مدیریت کامل، پیام همگانی، و مدیریت داینامیک ادمین‌ها.

---

## 🚀 قابلیت‌ها

| قابلیت | توضیحات |
|--------|----------|
| 📤 **آپلود فایل** | ادمین فایل‌ها را ارسال می‌کند و ربات در کانال دیتابیس ذخیره می‌کند و لینک دریافت ایجاد می‌شود |
| ⛔ **اتمام آپلود** | ساخت منیفست، لینک دریافت دایمی، و بازگشت کیبورد به حالت پنل |
| ⏱ **حذف خودکار** | پیام‌های اصلی فایل‌ها بعد از ۶۰ ثانیه پاک می‌شوند (نسخه DB Channel دست‌نخورده می‌ماند) |
| 📣 **پیام همگانی** | ارسال پیام یا مدیا به همه کاربران با فاصله ۰.۱ ثانیه (فیلتر Flood) و هندلING خطای مسدودشدن کاربران |
| 👥 **مدیریت ادمین‌ها** | افزودن/حذف/لیست/تاریخچه تغییرات ادمین‌ها (فقط مالک .env) |
| 🔒 **کانال‌های قفل‌شده** | عضویت اجباری در کانال‌ها قبل از دریافت فایل |
| 👁 **شرط سین/ری‌اکشن** | Basin conditional delivery — کاربر باید وارد کانال شود و ریاکشن بزند |
| 🔗 **لینک دایمی** | دکمه شیشه‌ای دریافت فایل‌ها در پیام اعلان حذف |
| 📊 **منیفست V1** | سه خط اول: هدر + وضعیت ویو چنل + وضعیت حذف خودکار؛ خطوط بعدی: آیدی فایل‌ها |

| متغیر | نوع | توضیحات |
|--------|-----|----------|
| `API_ID` | عدد | آیدی API از my.telegram.org |
| `API_HASH` | رشته | هش API از my.telegram.org |
| `BOT_TOKEN` | رشته | توکن ربات از @BotFather |
| `OWNER_IDS` | عدد (یا لیست با ویرگول) | **مالک ربات** — فقط این‌ها دکمه مدیریت ادمین‌ها را می‌بینند و قابل حذف نیستند |
| `DB_CHANNEL_ID` | عدد | آیدی کانال دیتابیس (ربات باید ادمین باشد) |
| `DATABASE` | رشته | نوع دیتابیس: `sqlite` (پیش‌فرض)، `postgres`، `mysql` |
| `DATABASE_URL` | رشته | اتصال دیتابیس برای Postgres/MySQL (فقط در غیر از sqlite) |
| `AUTO_DELETE_SECONDS` | عدد | زمان حذف خودکار پیام‌ها به ثانیه (پیش‌فرض: ۶۰) |
| `VIEW_CHANNEL_ID` | عدد | آیدی کانال ویو (اختیاری) |

> ⚠️ مالک‌های `OWNER_IDS` همیشه ادمین هستند، در جدول دیتابیس ذخیره نمی‌شوند و **قابل حذف نیستند**.

## 👥 پنل مدیریت

### منوی اصلی

دکمه‌های پنل اصلی برای **مالک**:
```
📤 آپلود فایل
🔒 مدیریت کانال‌های قفل‌شده
👁️ مدیریت شرط سین/ری‌اکشن
📣 پیام همگانی
👥 مدیریت ادمین‌ها
```

برای **ادمین‌های اضافه‌شده** (دیتابیس): دکمه مدیریت ادمین‌ها نمایش داده نمی‌شود.

### مدیریت ادمین‌ها (فقط مالک)

دسترسی از طریق دکمه `👥 مدیریت ادمین‌ها`:

| دکمه | عملکرد |
|------|---------|
| `📋 لیست ادمین‌ها` | نمایش مالکان `.env` و ادمین‌های فعال دیتابیس |
| `➕ افزودن ادمین` | دریافت آیدی عددی یا فوروارد پیام کاربر و افزودن به دیتابیس |
| `🗑 حذف ادمین` | نمایش لیست دکمه‌های حذف برای ادمین‌های فعال |
| `📜 تاریخچه تغییرات` | نمایش ۳۰ تغییر اخیر (افزودن/حذف با زمان و عامل) |

> ⚠️ مالک `.env` قابل حذف نیست.

## 📤र्कت آپلود فایل

1. ادمین روی `📤 آپلود فایل` می‌زند
2. فایل‌ها را یکی‌یکی یا پشت‌سرهم می‌فرستد (آلبوم‌ها پشتیبانی می‌شوند)
3. هر فایل در **کانال دیتابیس** کپی می‌شود (نیمه‌برداری)
4. با زدن `✅ اتمام آپلود`:
   - منیفست ساخته می‌شود (سه خط اول + آیدی فایل‌ها)
   - لینک دریافت دایمی (`t.me/bot?start=<payload>`) با دکمه شیشه‌ای ایجاد می‌شود
   - کیبورد به حالت پنل اصلی برمی‌گردد
5. اگر `حذف خودکار` روشن بود، پیام اصلی فایل ادمین بعد از ۶۰ ثانیه پاک می‌شود

## 📣 پیام همگانی

-ادمین روی `📣 پیام همگانی` می‌زند و پیام/مدیا را می‌فرستد
- ربات پیام را با `message.copy` به همه کاربران (excluding مالکان و ادمین‌ها) ارسال می‌کند
- فاصله **۰.۱ ثانیه** بین هر ارسال برای جلوگیری از Flood
- اگر `FloodWait` دریافت شود، صبر می‌کند و دوباره تلاش می‌کند
- اگر `PeerFlood` رخ دهد، ارسال متوقف می‌شود (جلوگیری از بن شدن ربات)
- کاربران بلاک‌شده یا غیرفعال بدون کرش ربات رد می‌شوند
- در نهایت گزارش ارسال‌شده / ناموفق / ردشده نمایش داده می‌شود

## 🔒 شرایط دریافت فایل

### عضویت اجباری (کانال‌های قفل‌شده)
اگر کاربر لینک دریافت را باز کند و در همه کانال‌های قفل‌شده عضو نباشد، دکمه‌های عضویت نمایش داده می‌شود و بعد از عضویت می‌تواند فایل‌ها را دریافت کند.

### شرط سین/ری‌اکشن (View Gate)
اگر منیفست فعال‌سازی Condition داشته باشد:
- کاربر پیام کانال ری‌اکشن را می‌بیند
- باید وارد کانال شود، پست‌ها را ببیند و ریاکشن بزند
- روی دکمه `📥 دریافت فایل` می‌زند (بدون نمایش الثانیه pozostał)
- پیام شرط پس از دریافت **کاملاً پاک می‌شود** (کاربر متوجه سنجش زمانی نمی‌شود)

## 🔐 منیفست (VDB Channel)

هر آپلود یک پیام منیفست در کانال دیتابیس می‌سازد:

```
UPLOADERBOT_MANIFEST_V1
VIEW_GATE=1
AUTO_DELETE=1
101
102
305
```

- خط ۱: هدر نسخه
- خط ۲: وضعیت شرط ویو چنل (`1` = فعال)
- خط ۳: وضعیت حذف خودکار (`1` = فعال)
- خطوط بعدی: آیدی پیام فایل‌ها در کانال دیتابیس

آیدی این پیام منیفست به عنوان `payload` در لینک دریافت استفاده می‌شود:
`https://t.me/<bot_username>?start=<base62_payload>`
